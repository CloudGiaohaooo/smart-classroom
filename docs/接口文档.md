# RESTful 接口文档

## 通用约定

- 基础路径：`http://localhost:8080`
- 认证：除登录接口外，均需在请求头携带 `Authorization: Bearer <token>`
- 统一响应体：

```json
{ "code": 200, "message": "操作成功", "data": { } }
```

| code | 含义 |
| --- | --- |
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录 / token 失效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器异常 |

分页接口统一返回：`{ "records": [], "total": 0, "current": 1, "size": 10 }`

---

## 1. 认证模块

### 1.1 登录

- `POST /api/auth/login`
- 请求体：`{ "username": "teacher", "password": "123456" }`
- 响应：`data` 为 `{ "token": "...", "user": { "id", "username", "realName", "role" } }`

### 1.2 当前用户信息

- `GET /api/auth/me`

## 2. 课程管理

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/courses?current=1&size=10&keyword=&teacherId=` | 分页查询课程 |
| GET | `/api/courses/all` | 全部课程（下拉框） |
| POST | `/api/courses` | 新增课程 |
| PUT | `/api/courses/{id}` | 修改课程 |
| DELETE | `/api/courses/{id}` | 删除课程 |

新增/修改请求体示例：

```json
{
  "courseName": "数据结构",
  "courseCode": "CS202",
  "teacherId": 2,
  "credit": 4.0,
  "semester": "2026-2027 第一学期",
  "description": "线性表、树、图等数据结构及其算法。",
  "status": 1
}
```

## 4. 作业提交与批阅反馈

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/submissions` | 学生提交作业 |
| GET | `/api/submissions?assignmentId=&studentId=&status=` | 分页查询提交（教师） |
| GET | `/api/submissions/my` | 当前学生的提交记录 |
| PUT | `/api/submissions/{id}/grade` | 批阅（打分 + 反馈） |

提交请求体：`{ "assignmentId": 1, "content": "已完成..." }`

批阅请求体：`{ "score": 88, "feedback": "思路清晰，注释完整" }`

---

## 5. 课程资源上传

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/resources/upload` | 上传资源（multipart） |
| GET | `/api/resources?courseId=` | 分页查询资源 |
| DELETE | `/api/resources/{id}` | 删除资源 |

上传表单字段：`courseId`（课程 ID）、`resourceType`（VIDEO/PDF/DOC/PPT/OTHER）、`file`（文件）。

## 接口测试建议

可使用 Postman 或浏览器开发者工具按上述文档逐个验证，重点关注：

1. 无 token 访问受保护接口 → 返回 401；
2. 学生访问批阅接口 → 返回 403（需补充权限校验）；
3. 分数超过满分 → 返回 400 业务错误；
4. 超过截止时间提交 → 返回 400。
