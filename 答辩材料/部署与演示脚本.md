# 部署与演示脚本

> 本文件为脱敏公开版。给「评委 / 面试官」演示时按本文动线走一遍，全程约 5 分钟。

## 一、一键启动

### 方式 1：本地开发启动（本机已有 MySQL / Node / Maven）

```bash
# 1. 确保 MySQL 已启动（root/root，库 youda_classroom 自动创建）
# 2. 可选：启动 Redis（不启动也能跑，自动降级直查 DB）

# 后端（端口 8080，首次启动自动建表 + 种入演示数据）
cd backend
mvn spring-boot:run

# 前端（端口 5173，vite 代理 /api、/files 到 8080）
cd frontend
npm install
npm run dev
```

访问：前端 http://localhost:5173 ，Swagger http://localhost:8080/swagger-ui/index.html

### 方式 2：Docker 一键起（新机器）

```bash
docker compose up -d --build
# 前端 http://localhost ，后端 http://localhost:8080
```

## 三、演示动线（推荐顺序）

### 第 1 步：登录、选课与权限隔离（对应 Phase 2 / 18）
1. 用 `student` 登录 → 直达「课程管理」，看到自己已选修的课程；
2. 进入「选课中心」→ 浏览全部课程、点「选课 / 退课」，课程列表与作业/资源下拉实时联动（选课模型 Phase 18）；
3. 切到 `teacher` → 演示「批阅」；尝试用 student 调批阅接口会返回 403（可口头说明 `@PreAuthorize`）；
4. 未登录直接访问接口 → 401。

### 第 2 步：智能辅助批阅（创新点 A）
1. `teacher` 进入「作业批阅」→ 筛出「实验二：数组与函数（雷同检测演示）」；
2. 点任意一条**待批阅**提交 → 弹窗展示：
   - **相似提交提示**：同簇提交相似度约 99%（同簇实测）、标红「疑似雷同」；
   - **推荐评语**：3 条历史高频评语，点「填入」一键填充；
3. 打分 + 提交，验证原批阅事务链路正常。

### 第 3 步：学习预警看板（创新点 B）
1. `teacher` 进入「数据概览」→ 展示提交率趋势折线 + 资源访问热度柱状 + 学习预警列表；
2. 预警列表出现 3 名「长期未登录、长期未提交作业」学生（demo18~20）；
3. （可选）用 `demo18` 登录一次 → 回到看板刷新，其「长期未登录」预警实时消失。

### 第 4 步：工程深度收尾
1. 打开 Swagger UI，展示接口文档与 JWT Authorize；
2. 口头说明：`mvn test` 61 例全绿（含 Testcontainers）+ Docker 一键部署。

## 四、答辩话术要点（30 秒电梯陈述）

> 这个项目是前后端分离的教学管理平台，我在基础 CRUD 之上做了两块「智能」增量：
> 一是**智能辅助批阅**，用纯 Java 的 TF-IDF + 余弦相似度做雷同检测和历史评语推荐，不依赖大模型；
> 二是**学习预警看板**，用 AOP 注解切面零侵入埋点，把登录/看资源/交作业三类行为落到埋点表，按外置规则实时预警。
> 同时补齐了 RBAC 权限、Redis 缓存三策略、SpringDoc 文档、单测覆盖率和 Docker 部署这些工程深度。
