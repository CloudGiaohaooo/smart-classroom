## 第 4 页 · 项目背景与目标
- 痛点：传统教学管理流程依赖人工，作业发布/批阅/资源分发效率低、易出错
- 目标：构建一个覆盖「课程—作业—提交—批阅—资源」的教学管理平台
- 我的职责：独立完成课程管理、作业列表前端页面；协助开发资源上传、作业批阅反馈后端接口

## 第 5 页 · 系统架构（放架构图）
- 前后端分离：Vue3 + Spring Boot
- 三层架构：Controller → Service → Mapper → MySQL
- 一句话讲清数据流：浏览器 → RESTful 接口 → 业务逻辑 → 数据库

## 第 6 页 · 技术选型
| 层 | 技术 | 选型理由 |
| --- | --- | --- |
| 前端 | Vue3 + Element Plus | 组件化、生态成熟 |
| 后端 | Spring Boot 3 + MyBatis-Plus | 快速开发、SQL 灵活 |
| 数据库 | MySQL 8 | 关系型、事务支持 |
| 安全 | JWT + BCrypt | 无状态认证、密码加密 |

## 第 12 页 · 技术难点与解决
1. **多表查询**：LEFT JOIN + 聚合子查询统计提交数/批阅数
2. **事务一致**：批阅操作 @Transactional 保证原子性
3. **无状态认证**：JWT + 拦截器 + ThreadLocal 上下文
4. **文件上传安全**：UUID 重命名、按课程分目录
