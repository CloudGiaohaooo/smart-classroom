## 第 12 页 · 技术难点与解决
1. **多表查询**：LEFT JOIN + 聚合子查询统计提交数/批阅数
2. **事务一致**：批阅操作 @Transactional 保证原子性
3. **无状态认证 + RBAC**：JWT + Spring Security 过滤链 + ThreadLocal 上下文 + @PreAuthorize 方法级授权
4. **文件上传安全**：UUID 重命名、按课程分目录
5. **工程尝试 A · 智能辅助批阅**：TF-IDF + 余弦相似度做雷同检测，历史评语一键推荐（辅助初筛，最终判定由教师确认）
6. **工程尝试 B · 学习预警看板**：AOP 注解零侵入埋点 + ECharts 可视化 + 外置预警规则
7. **工程尝试 C · 课程资源 MD5 秒传去重**：JDK MessageDigest 计算 MD5 + 同文件复用不重复落盘 + 引用计数删除
8. **闭环故事线**：埋点 → 聚合 → 预警 → 干预 → 批阅辅助 → 评估（放数据流图，这是记忆点）
9. **可观测性**：traceId 日志链路（`X-Trace-Id` 贯穿请求 + MDC 日志）

## 第 14 页 · 关键技术决策（为什么这么选）
1. 认证：Spring Security 过滤链 + JWT，而非拦截器（方法级授权）
2. 雷同检测：TF-IDF 字符 n-gram，而非大模型 / 词典（离线、可复现、隐私）
3. 预警：规则阈值，而非规则引擎 / ML（数据不足时不硬上黑盒）
4. 埋点：AOP 异步落库，而非同步（不拖慢业务）
5. 权限缓存：Caffeine 本地，而非 Redis（高频读零网络开销）
6. 下载鉴权：签名 URL，而非登录 header（浏览器跳转无法带头）

> 完整 12 条见 `docs/DESIGN_DECISIONS.md`（含 Redis key 设计与并发一致性）。
