## 动线（推荐顺序）

### ① 登录 + 选课（选课模型 Phase 18）
1. `student` 登录 → 按角色直达「课程管理」，看到自己已选修的课程；
2. 进「选课中心」→ 浏览全部课程，点「选课 / 退课」→ 课程列表与作业、资源下拉实时联动；
3. **说**：后端做了选课模型 `course_enrollment`，学生只看/交自己选的课，对未选课程提交会被 403 拦截。

### ② 学生提交作业（防重复 + 防超期）
1. `student`「作业列表」→ 点「提交作业」填内容提交；
2. 已提交 / 已截止的作业按钮会置灰（「已提交 / 已截止」标识）；
3. **说**：提交有「唯一索引 + 业务预查重」双重防重复，超截止时间拒绝提交。

### ③ 教师智能辅助批阅（创新点 A）
1. `teacher`「作业批阅」→ 筛出「实验二：数组与函数（雷同检测演示）」；
2. 点一条**待批阅**提交 → 弹窗展示：相似提交提示（同簇约 99%、标红「疑似雷同」）+ 3 条推荐评语（点「填入」一键填充）；
3. 打分 + 提交；
4. **说**：纯 Java TF-IDF + 余弦，离线不依赖大模型；阈值 0.45 → P/R/F1 = 1.0/1.0/1.0，0.75 → 1.0/0.625/0.769（100 对标注集评测）。

### ④ 学习预警看板（创新点 B）
1. `teacher`「数据概览」→ 提交率趋势折线 + 资源访问热度柱状 + 学习预警列表；
2. （可选）用 `demo18` 登录一次 → 回看板刷新，其「长期未登录」预警实时消失；
3. **说**：`@BehaviorLog` AOP 注解零侵入埋点 + 规则阈值外置，非 ML 预测。

### ⑤ 资源 MD5 秒传去重（创新点 C）
1. `teacher`「课程资源」→ 上传同一文件两次；
2. 第二次提示「秒传成功：相同文件已存在，已复用」；
3. **说**：JDK MessageDigest 算 MD5，命中复用物理文件、删除按引用计数。

### ⑥ 工程深度收尾
1. 打开 Swagger `http://localhost:8080/swagger-ui/index.html`，展示接口文档与 JWT Authorize；
2. **说**：`mvn test` 61 例全绿（含 Testcontainers 真实 MySQL）+ GitHub Actions CI + Docker 一键部署。

## 口径提醒（诚实边界）

- 「智慧」定位为**三个工程小尝试**（雷同检测 / 预警看板 / 秒传去重），不是研究创新点；
- 演示数据由初始化脚本 / 模拟生成器产生（`demo.simulated.enabled=false` 默认关闭），**非真实采集数据**；
- 主动说局限：单体架构、阈值经验值、合成标注集负例偏简单、压测为开发机下限。
- 雷同阈值口径：评测用**文本标注集** 0.45/0.75（F1=1.0/0.769）；代码演示数据因公共模板（`#include`/`main`/`printf`）基线相似度更高，运行时 `suspicious-threshold` 调至 **0.9** 以区分同簇/跨簇（阈值外置可调）。
